# MindEase V2 — Fixed Dashboard Starter

This is a working frontend starter with:
- Dashboard and Weekly Analysis as separate routes
- Colourful light theme and emerald dark theme shared across pages
- Responsive mobile layout
- Daily Insight card with a short current-mood explanation placeholder
- Weekly emotion chart for four major emotions (sample data clearly labelled)
- Header profile and settings actions
- Weekly Analysis shortcut replacing Add Task in the dashboard feature grid

## Run
```bash
cd frontend
npm install
npm run dev
```

## Important
This is the frontend foundation. Mood percentages and Daily Insight are demo placeholders until we connect the backend and real chatbot analysis. They must not be presented as real measurements. Only eligible AI chatbot mood-analysis results should feed reports; face scans and counselling chats remain excluded.
